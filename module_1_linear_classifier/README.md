This module focuses on two things:
1. The importance of examining your data. In this case, we use Linear Regression to prove to ourselves the two classes of fish are actually different.
2. Linear Classification -- that the equation for a line can be turned into a very, very simple Neural Network. Concepts like scaling the input data, weights, gradient descent (feed forward, loss, gradients, and back propogation), and binary classification (sigmoids) are introduced.
